# Forensic Activity Classification from iPhone Digital Traces: A Large Language Model Approach


This repository contains the preprocessed datasets, flowcharts, and experimental evaluation tables for our paper, **"Forensic Activity Classification from iPhone Digital Traces: A Large Language Model Approach."**

（The original dataset is publicly available on Hugging Face: [NFI_FARED Digital Traces](https://huggingface.co/datasets/NetherlandsForensicInstitute/NFI_FARED_Digital_Traces).）

## Code Availability

We will open-source the model code after publication.
